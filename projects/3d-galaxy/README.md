# 🌌 3D 银河

一个可在浏览器中实时探索的 Three.js 粒子银河。星体沿密度波模型持续流动，并配有辉光、尘埃、脉冲和可调参数，让单个 HTML 文件也能呈现完整的交互式 3D 场景。

## 主要功能

- 大规模粒子构成的旋涡银河、星核、年轻星群、尘埃和背景星空
- 鼠标拖动或触摸环绕视角，滚轮或双指缩放
- 暂停流动、释放脉冲、重置视角和重新生成银河
- 调节粒子密度、旋臂、亮度、辉光、曝光和运动速度
- 根据设备类型选择默认粒子密度，并适配窄屏和减少动态效果偏好
- Three.js CDN 多源回退与 WebGL2 不可用时的错误提示

## 技术栈

- HTML、CSS、JavaScript（单文件应用）
- Three.js `0.184.0`
- OrbitControls
- EffectComposer、UnrealBloomPass、OutputPass
- WebGL2 与 GLSL 粒子着色器

## 本地运行

这个项目不需要安装依赖或执行构建。首次加载需要联网获取 Three.js。

### 方式一：直接打开

双击 `index.html`，使用新版 Chrome、Edge、Firefox 或 Safari 打开。

### 方式二：启动本地服务器

在仓库根目录运行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/projects/3d-galaxy/
```

## 操作说明

| 操作 | 效果 |
| :--- | :--- |
| 鼠标拖动 / 单指拖动 | 环绕银河 |
| 滚轮 / 双指缩放 | 拉近或拉远 |
| 双击 / `F` | 释放脉冲 |
| 空格 | 暂停或继续 |
| `R` | 复位视角 |
| `H` | 隐藏或显示界面 |
| 参数按钮 | 调整画面与性能参数 |

## 已知限制

- 浏览器需要支持 WebGL2，并建议开启硬件加速。
- 当前版本从公共 CDN 加载 Three.js，完全离线时无法启动。
- 高粒子密度和高像素比会明显增加 GPU 负载；移动设备建议使用中低密度。
- 不同显卡和浏览器的辉光、色彩及帧率可能略有差异。
