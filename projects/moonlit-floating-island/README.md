# 🌙 月光浮空岛

一个使用 AI Coding 制作的交互式 3D 浮空岛。场景包含浮空岛、古树、遗迹、瀑布、魔法水晶、粒子效果以及动态昼夜光照。

## 基于什么制作

- HTML、CSS、JavaScript
- Three.js `0.150.1`
- WebGL / GLSL 着色器
- Web Audio API 程序化音效
- 程序化建模与粒子动画

项目以单个 `index.html` 文件交付，不需要安装 Node.js 或其他依赖。打开页面时需要联网加载 Three.js。

## 如何运行

使用新版 Chrome、Edge、Firefox 或 Safari 打开 `index.html` 即可。

## 如何操作

### 电脑端

| 操作 | 效果 |
| :--- | :--- |
| 鼠标拖动 | 旋转视角 |
| 鼠标滚轮 | 拉近或拉远 |
| 悬停水晶 | 水晶放大并高亮 |
| 点击水晶 | 释放能量与旋律 |
| 空格键 | 切换月夜、破晓、清晨、正午、黄昏和极光夜 |
| `R` 键 | 重置镜头 |

### 移动端

| 操作 | 效果 |
| :--- | :--- |
| 单指拖动 | 旋转视角 |
| 双指缩放 | 拉近或拉远 |
| 点击水晶 | 释放能量 |
| 切换时间按钮 | 进入下一个时段 |
| 重置镜头按钮 | 恢复默认视角 |

点亮全部七枚水晶后，浮空岛会进入短暂的苏醒状态。
