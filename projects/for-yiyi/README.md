# ✨ 致 yiyi · 银河告白

一个完全离线、双击即可打开的互动式银河告白页面。整片星空由纪念日期作为随机种子生成，故事分为远望、点亮、连线、名字与提问四幕，并支持生成专属星图留念。

## 主要功能

- 单个 `index.html` 文件，不需要 Node.js、本地服务器或网络
- 使用日期作为随机种子，稳定生成同一片银河
- 四幕式故事流程与自动播放，也可以点击或按键加快字幕
- 点亮 2–7 颗回忆之星，并按顺序连成专属星座
- 9000 颗星从银河升起，汇成自定义名字
- “我愿意”和“让我想一想”两条完整回答分支
- 支持静音、重新观看和生成 PNG 星图
- 适配触摸屏、窄屏与减少动态效果偏好

## 技术实现

- HTML、CSS、JavaScript 单文件应用
- 原生 WebGL2 与 GLSL ES 3.00 着色器
- Canvas 2D 文字采样与星图合成
- Web Audio API 程序化音效
- 无框架、无第三方运行时依赖、无外部素材

## 本地运行

直接双击 `index.html`，使用新版 Chrome、Edge、Firefox 或 Safari 打开即可。

项目不会请求网络资源，也不需要安装或启动任何开发工具。

## 使用前自定义

用文本编辑器打开 `index.html`，搜索：

```html
id="letter"
```

页面中的可编辑文字都在这段 JSON 内。修改后请保持合法 JSON 格式，使用英文双引号，并注意项目之间的逗号。

### 回忆文案

修改 `memories` 数组。这里可以设置 2–7 条属于使用者自己的回忆，每点亮一颗星会显示一条。

```json
"memories": [
  "第一条共同回忆。",
  "第二条共同回忆。"
]
```

为了避免手机上出现不自然的折行，建议每行不超过 16 个汉字。需要主动换行时，在 JSON 字符串中写 `\n`。

### 纪念日期

修改 `date` 和 `dateMeaning`：

```json
"date": "2026-10-01",
"dateMeaning": "我们的纪念日"
```

- `date` 可以填写相遇日、纪念日或其他重要日期，并会决定这片银河的随机种子。
- `dateMeaning` 是页面中对这一天的解释，例如“我遇见你的那天”或“我们的纪念日”。
- 修改日期会生成一片不同但可重复出现的星空。

还可以修改 `name`，决定最后由 9000 颗星拼出的名字。

## 操作说明

| 操作 | 效果 |
| :--- | :--- |
| 轻触封面 | 开始故事 |
| 点击空白处 / 空格 / 回车 | 加快当前字幕 |
| 点击亮星 | 点亮一条回忆 |
| 从第一颗星按住并依次划过 | 连接星座 |
| 依次点击每颗星 | 另一种连接方式 |
| 右上角按钮 / `M` | 静音或恢复声音 |

完整自动播放通常约 60–90 秒。

## 故事流程

1. **远望**：镜头从远处飞向银河，依次显示四句开场字幕。
2. **点亮**：点亮最亮的回忆之星，每颗星对应一句可自定义回忆。
3. **连线**：按照提示依次划过或点击星星，连接专属星座。
4. **名字与提问**：星星汇成名字，并显示最终提问与两个同等大小的回答按钮。

选择“我愿意”后会显示当天日期，并可生成和保存星图。选择“让我想一想”后，可以稍后点击“我想好了”继续。

## 已知限制

- 浏览器必须支持 WebGL2，建议开启硬件加速。
- 浏览器会在首次点击封面后才允许播放声音，这是正常的媒体播放限制。
- 部分手机浏览器不会直接下载图片，而是显示星图供长按保存。
- 字体由设备提供，不同系统上名字的字形可能略有差异。
