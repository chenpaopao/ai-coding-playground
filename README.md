## 👋 关于这个仓库

`ai-coding-playground` 是我的 AI Coding 作品集，也是一个持续更新的 AI 编程实验场。

我会使用 AI 编程工具，把日常冒出的想法逐步变成小游戏、实用工具、Web 应用与创意实验。AI 会参与需求拆解、技术选型、界面设计、代码实现、调试和迭代，而我负责提出目标、做出判断并验收最终结果。

这些项目不一定庞大，也不一定完美，但都希望做到：

- 💡 **有想法**：解决一个问题，或者带来一点乐趣
- ▶️ **能运行**：不是只有截图或概念，而是可以亲自体验
- 📖 **易理解**：每个项目都有介绍、运行方法和必要说明
- 🔓 **可学习**：公开实现过程与源代码，供学习和交流
- 🤖 **AI 共创**：诚实记录 AI 在项目中的参与方式

> AI 可以让一个想法更快落地，但真正重要的仍然是提出问题、做出选择，以及不断把作品打磨得更好。

## 🧭 项目理念

这个仓库想探索的不只是“AI 能不能写代码”，还有这些更有意思的问题：

1. 一个普通想法，能否借助 AI 快速变成可玩的作品？
2. 不同 AI 工具分别适合参与产品、设计、开发和测试的哪些环节？
3. 人应该如何描述需求、判断结果，并把 AI 生成的代码变成可靠的软件？
4. AI Coding 能否降低创作门槛，让更多人开始构建自己的工具和游戏？

我会用一个个小项目寻找答案。

## 🛠️ 创作方式

一个项目通常会经历以下过程：

```text
灵感 / 问题
    ↓
明确目标与最小可行版本
    ↓
与 AI 讨论方案和技术选型
    ↓
AI 辅助编写、解释和重构代码
    ↓
人工体验、判断、调试与迭代
    ↓
整理文档并发布
```

AI 可能参与的工作包括：

- 梳理需求与拆分任务
- 生成原型和基础代码
- 设计界面与交互方案
- 排查错误与补充测试
- 优化性能与代码结构
- 编写说明文档

所有项目都会经过人工检查和实际运行。AI 是创作伙伴，而不是最终质量的保证者。

## 🚀 如何运行

克隆整个仓库：

```bash
git clone https://github.com/chenpaopao/ai-coding-playground.git
cd ai-coding-playground
```

进入想体验的项目，并按照该项目目录中的 `README.md` 操作：

```bash
cd projects/3d-galaxy
```

这些项目均可按照各自 README 中的说明运行。`moonlit-floating-island` 是单文件项目，打开 `index.html` 即可体验，但需要联网加载 Three.js。
